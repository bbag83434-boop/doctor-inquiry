# Doctor Inquiry

A production-ready web application for managing doctor inquiries, built with React 19 and Node.js.

## Project Structure

- `frontend/`: React 19 + Vite frontend (PWA).
- `backend/`: Node.js + Express backend.
- `docs/`: Project documentation.

## Setup Instructions

### Backend
1. Navigate to `backend/`.
2. Run `npm install`.
3. Create a `.env` file based on `.env.example`.
4. Run `npm run dev` to start the server.

### Frontend
1. Navigate to `frontend/`.
2. Run `npm install`.
3. Create a `.env` file based on `.env.example`.
4. Run `npm run dev` to start the development server.
